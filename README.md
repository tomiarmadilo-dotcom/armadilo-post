# Armadilo Post

Armadilo Post is a lightweight, web-based Peer-to-Peer (P2P) file transfer application designed for fast, direct, and secure data sharing between devices. 

Unlike traditional cloud storage services, Armadilo Post **requires absolutely no account registration or login**. No emails, no passwords, no hassle. Just open the web app, drop your file, and share the link.

## 🌟 Key Features

- **Zero Login Required:** Skip the sign-up process entirely. You don't need an account to send or receive files. Simply open the web app and start transferring instantly.
- **True Privacy (Zero Server Storage):** Your files are never uploaded to or stored on a server. Data flows directly from the sender's browser to the receiver's browser using WebRTC technology. Our server is only used for the initial connection handshake, after which your data travels securely peer-to-peer.
- **Instant QR Code Generation:** No need to type or copy long, complex URLs. The sender can generate a QR code, allowing the receiver to simply scan it with their phone camera to connect and download instantly. Perfect for cross-device transfers.
- **Minimalist Dark Theme:** A clean, modern, and distraction-free dark mode interface designed for optimal visual comfort.

## 🚀 How to Use

1. Open the Armadilo Post web app.
2. Drag and drop the file you want to send into the designated area.
3. Click **Buat Link** (Generate Link).
4. Share the generated link or let the receiver scan the QR code.
5. The receiver opens the link, clicks **Hubungkan dan Unduh** (Connect and Download), and the file transfers directly to their device.
6. *Important Note: The sender must keep the browser tab open during the entire transfer process.*

## 🛡️ Security Note

Because the connection is strictly P2P and requires no login, transfer links are temporary and private. Please do not share your transfer link with untrusted parties. Closing the sender's tab immediately after the transfer ends will terminate the session.
